# bot-portfolio
bot portfolio

Этот бот сохраняет проекты для вас

Команды:
  
  📁 /new_project - используй для добавления нового проекта
  
  🧰 /skills - добавление навыков к проекту
  
  📁 /projects - просмотр всех твоих проектов
  
  🗑️ /delete - удаление проекта
  
  ✏️ /update_projects - обновление информации о проекте
