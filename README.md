Telegram-бот для ведения портфолио проектов: добавляйте проекты, назначайте им статусы и навыки, просматривайте и обновляйте информацию прямо в чате.

## Возможности

- Добавление нового проекта (`/new_project`)
- Просмотр списка проектов (`/projects`)
- Просмотр подробной информации по проекту (вводом имени проекта)
- Добавление и удаление навыков у проекта (`/skills`)
- Обновление полей проекта (`/update_projects`)
- Удаление проекта (`/delete`)

## Команды бота

- 📁 `/new_project` — добавить новый проект
- 🧰 `/skills` — добавить/удалить навыки проекта
- 📁 `/projects` — показать все проекты
- 🗑️ `/delete` — удалить проект
- ✏️ `/update_projects` — изменить данные проекта
- ℹ️ `/info` — показать справку

## Стек

- Python 3
- [pyTelegramBotAPI](https://pypi.org/project/pyTelegramBotAPI/)
- SQLite

## Структура проекта

- `main.py` — Telegram-бот и обработчики команд
- `logic.py` — работа с базой данных (создание таблиц, CRUD)
- `config.py` — конфигурация (токен, БД, кнопки, emoji)
- `bot-portfolio.db` — SQLite-база (создаётся/используется приложением)

## Быстрый старт

1. Клонируйте репозиторий.
2. Установите зависимости:

```bash
pip install pyTelegramBotAPI
```

3. Откройте `config.py` и укажите токен вашего Telegram-бота:

```python
TOKEN = 'YOUR_TELEGRAM_BOT_TOKEN'
```

4. Запустите бота:

```bash
python main.py
```

## База данных

При старте создаются таблицы:

- `projects`
- `skills`
- `project_skills`
- `status`

Также автоматически добавляются базовые статусы и навыки (через `default_insert`).

## Примечания

- Если у пользователя ещё нет проектов, бот подскажет добавить первый через `/new_project`.
- Кнопка отмены настраивается в `config.py` через `CANCEL_BUTTON`.
